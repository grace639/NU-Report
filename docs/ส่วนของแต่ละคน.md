# NU Report — การแบ่งงานและสิ่งที่แต่ละคนต้องอธิบายได้

> เกณฑ์ B1 (30 คะแนน) ถามเฉพาะไฟล์ที่ตัวเองระบุในฟอร์ม 3 และให้เปิดโค้ดประกอบได้
> ทุกคนต้อง **อ่านไฟล์ของตัวเองให้เข้าใจทุกบรรทัด** ลองแก้ด้วยตัวเองอย่างน้อย 1 อย่าง และเป็นคนกดสาธิตเอง (B2)

## ความต้องการ R1–R5 (ร่าง — ต้องปรับตามที่ผู้ใช้จริงบอก)

| รหัส | ความต้องการ | เกณฑ์ยืนยันความสำเร็จ (กดอะไรแล้วเห็นอะไร) |
|---|---|---|
| R1 | แจ้งปัญหาพร้อมหลักฐาน | ปุ่ม "แจ้งปัญหา" → กรอกหัวข้อ หมวดหมู่ สถานที่ รายละเอียด แนบรูปจากกล้องหรือคลังรูป → ส่งแล้วเห็นในรายการทันทีด้วยสถานะ "รอดำเนินการ" |
| R2 | ตามหาเรื่องที่เคยแจ้งได้เร็ว | พิมพ์คำในช่องค้นหา (ค้นทั้งหัวข้อ รายละเอียด สถานที่) + กรองสถานะ/หมวดหมู่ แล้วรายการเปลี่ยนตาม |
| R3 | เจ้าหน้าที่จัดการเรื่องได้ | ล็อกอินแอดมิน → เปิดเรื่อง → "เปลี่ยนสถานะ" + หมายเหตุ → สถานะเปลี่ยนและมีประวัติในหน้ารายละเอียด |
| R4 | ผู้แจ้งรู้ว่าเรื่องมีความคืบหน้า | หลังแอดมินเปลี่ยนสถานะ ผู้แจ้งเปิดแอปเห็นแถบสีแสด "มี N เรื่องที่มีความคืบหน้าใหม่" + จุดแสดในรายการ เปิดดูแล้วหายไป |
| R5 | สรุปผลรายเดือน | แท็บ "สรุปผล" → เลือกเดือน → กราฟตามสถานะ/หมวดหมู่ → "ส่งออก CSV" ได้ไฟล์ที่เปิดใน Excel แล้วภาษาไทยอ่านได้ |
| R6 | เจ้าหน้าที่ประชาสัมพันธ์ข่าวให้ผู้ใช้ทุกคน | แอดมิน → แท็บ "ประชาสัมพันธ์" → "ประกาศใหม่" (ติ๊กปักหมุดได้) → ผู้ใช้ทุกคนเห็นในแท็บเดียวกัน ประกาศปักหมุดอยู่บนสุด แอดมินเลิกปักหมุด/ลบได้ |

> ฟอร์มกำหนด R1–R5 ถ้าต้องการ 5 ข้อพอดี ให้รวม R6 เข้ากับ R4 เป็น "ผู้ใช้รับรู้ความคืบหน้าและข่าวสารจากเจ้าหน้าที่"

## สมาชิกคนที่ 1 — ฐานข้อมูล + ค้นหา (R2) · แนะนำ 30%

**ไฟล์:** `lib/db/database_helper.dart` · `lib/db/user_dao.dart` · `lib/db/report_dao.dart` · `lib/db/comment_dao.dart` · `lib/models/*` · `lib/providers/report_provider.dart` · `lib/screens/report_list_screen.dart` · `lib/services/link_guard.dart` (ป้องกันลิงก์แปลกปลอม ตามที่ผู้ใช้ขอ)

**ต้องอธิบายได้**
- ตาราง 4 ตาราง ความสัมพันธ์ (FK) และทำไมต้อง `PRAGMA foreign_keys = ON`
- `onCreate` ทำงานเมื่อไร ทำไมใช้ Singleton (`DatabaseHelper.instance`)
- `whereArgs` / `?` ป้องกัน SQL injection อย่างไร
- `search()` ประกอบ WHERE แบบมีเงื่อนไขอย่างไร, `LIKE '%คำ%'`
- `updateStatus()` ใช้ transaction เพราะอะไร
- ทำไมเก็บวันที่เป็น ISO-8601 string (เทียบช่วงวันได้)
- debounce ในช่องค้นหา (Timer 400ms) ช่วยอะไร
- `ReportProvider` + `notifyListeners()` ทำให้หน้าจออัปเดตได้อย่างไร
- **ป้องกันลิงก์แปลกปลอม (change log):** regex ใน `LinkGuard` จับลิงก์ 3 แบบ (`http(s)://`, `www.`, โดเมนลอยๆ เช่น `bit.ly/x`), เรื่องแจ้งปัญหาห้ามมีลิงก์เลย (`noLinks`), ประกาศมีได้เฉพาะ `nu.ac.th` (`onlyTrustedLinks`), ทำไมเช็ก `endsWith('.nu.ac.th')` ไม่ใช้ `contains` (กันเว็บปลอม `nu.ac.th.evil.com`), ทำไม regex ไม่จับข้อความไทยอย่าง "ต.ค." และ unit test 2 ตัวใน `test/widget_test.dart`

**สาธิต:** ค้นหา/กรองหลายแบบ · เปิดไฟล์ schema อธิบายตาราง

**คำถามเฉพาะหน้าที่อาจโดน:** "ถ้าจะเพิ่มคอลัมน์ priority ต้องแก้อะไร" → เพิ่มใน CREATE TABLE + model + เพิ่ม `_dbVersion` และเขียน `onUpgrade` (`ALTER TABLE`) — ดูตัวอย่างจริงได้ที่ v2 ซึ่งเพิ่มตาราง announcements ผ่าน `onUpgrade` (เครื่องที่ลงแอปไว้แล้วข้อมูลเดิมไม่หาย)

## สมาชิกคนที่ 2 — หน้าจอแจ้งปัญหา + ธีม + ประชาสัมพันธ์ (R1, R6) · แนะนำ 25%

**ไฟล์:** `lib/screens/create_report_screen.dart` · `lib/services/image_service.dart` · `lib/screens/home_screen.dart` · `lib/screens/announcements_screen.dart` · `lib/db/announcement_dao.dart` · `lib/models/announcement.dart` · `lib/theme/app_theme.dart` · `lib/widgets/report_card.dart` · `lib/widgets/report_image.dart` · `lib/widgets/status_chip.dart` · `lib/widgets/feedback.dart`

**ต้องอธิบายได้**
- `Form` + `GlobalKey<FormState>` + `validator` ทำงานอย่างไร
- `image_picker` ถ่าย/เลือกรูป และทำไมต้อง copy ไปเก็บใน documents directory
- `_saving` ป้องกันกดซ้ำ, try/catch/finally + `mounted`
- ธีมสีเทา-แสด รวมไว้ที่ `AppTheme` ทำไม
- `NavigationBar` ในหน้าแรก: ทำไมแอดมินกับผู้ใช้เห็นแท็บต่างกัน และทำไมใช้ `tabs[_tab]` แทน `IndexedStack` (สลับแท็บแล้วโหลดข้อมูลใหม่)
- ประชาสัมพันธ์: `ORDER BY pinned DESC, created_at DESC` ทำให้ปักหมุดอยู่บนสุดอย่างไร, ทำไมแอดมินเห็นปุ่ม "ประกาศใหม่" แต่ผู้ใช้ไม่เห็น, ยืนยันก่อนลบด้วย `showDialog<bool>`
- `heroTag` ของ FloatingActionButton ใส่ไว้ทำไม (มี FAB หลายหน้า)
- **แนะนำ:** มีไฟล์ออกแบบ (Figma) แสดงในวันนำเสนอด้วย

**สาธิต:** แจ้งปัญหาพร้อมถ่ายรูป · กดส่งโดยไม่กรอกให้เห็นข้อความเตือน · แอดมินโพสต์ประกาศแบบปักหมุด แล้วล็อกอิน user ให้เห็นประกาศ

## สมาชิกคนที่ 3 — ระบบสมาชิก + จัดการเรื่องของแอดมิน (R3) · แนะนำ 20%

**ไฟล์:** `lib/providers/auth_provider.dart` · `lib/services/password_hasher.dart` · `lib/screens/login_screen.dart` · `lib/screens/register_screen.dart` · `lib/screens/report_detail_screen.dart` · `lib/main.dart`

**ต้องอธิบายได้**
- SHA-256 + salt ทำไมไม่เก็บรหัสผ่านตรงๆ
- ทำไมข้อความ error login ไม่บอกว่าผิดที่ชื่อหรือรหัส
- `Consumer<AuthProvider>` ใน `main.dart` สลับหน้า login/หน้าแรกเองได้อย่างไร
- `FutureBuilder` + `Future.wait` ในหน้ารายละเอียด, สถานะ waiting/error
- Dialog เปลี่ยนสถานะคืนค่ากลับด้วย `Navigator.pop(context, value)`
- ทำไมอ่าน `context.read` ก่อน `await`

**สาธิต:** สมัคร/ล็อกอินผิด-ถูก · ล็อกอินแอดมินเปลี่ยนสถานะ + หมายเหตุ

## สมาชิกคนที่ 4 — การแจ้งอัปเดต + สรุปผล (R4, R5) + ทดสอบ · แนะนำ 25%

**ไฟล์:** `lib/widgets/update_banner.dart` · `lib/screens/admin/dashboard_screen.dart` · `lib/services/csv_export_service.dart` · `test/widget_test.dart` · บันทึกการทดสอบ · สไลด์
